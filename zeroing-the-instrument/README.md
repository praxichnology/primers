# Zeroing the Instrument

*A primer on null-control batteries for software-based measurement*

**Christian S. Loh, Ph.D., and Yanyan Sheng, Ph.D.**

A Praxichnology Teaching Resource.

This Primer explains how software can operate as designed while producing
records or patterns that do not support the intended interpretation.

The combined PDF includes a companion casebook in Appendix A, with guided
lessons and worked answers. The examples are synthetic instructional materials,
not empirical findings about human participants.

Example data and verification code support optional inspection and reproduction
of the calculations. Python is not required to read the Primer or casebook.

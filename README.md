# Praxichnology Primers

Teaching resources for researchers, developers, and students working with
activity traces and software-based measurement.

Each primer introduces a problem, explains the underlying reasoning,
and provides worked examples. Companion data and verification code are
included where appropriate.

## 1. Zeroing the instrument — _A primer on null-control batteries for software-based measurement_

**Christian S. Loh, Ph.D., and Yanyan Sheng, Ph.D.**

How can software operate as designed while producing records or patterns
that do not support the intended interpretation?

This Primer introduces null-control batteries for examining that risk.
It includes a companion casebook with guided lessons and worked answers.

[Read the Primer and access companion materials](zeroing-the-instrument/)
